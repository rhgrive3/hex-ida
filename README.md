# hex

[![Test](https://img.shields.io/badge/tests-passing-brightgreen.svg)]()
[![Platform](https://img.shields.io/badge/platform-Web%20%2F%20Safari%20%2F%20Chrome-blue.svg)]()
[![Arch](https://img.shields.io/badge/arch-ARM64%20(AArch64)-orange.svg)]()
[![License](https://img.shields.io/badge/license-MIT-green.svg)]()

**hex** は、iOS / macOS の Mach-O（ARM64）や生バイナリをブラウザ上で解析・逆アセンブル・デコンパイルするための対話型リバースエンジニアリングツールです。

バイナリのアップロードや外部通信は一切行わず、Web Worker と WebAssembly（Capstone 5）を活用してすべての解析処理を端末内でローカルに完結します。

---

## 主な特徴

- **完全ローカル・プライバシー優先**
  - 開いたバイナリが外部サーバーに送信されることはありません。
  - 解析、逆アセンブル、検索、エミュレーションの全工程がブラウザの Web Worker 内で実行されます。
- **目的指向の解析 (Goal-Oriented Analysis)**
  - 「HP」「攻撃力」「課金」「通信」「チート対策」などの目的を選ぶだけで、該当する関数・命令・変数の候補を根拠付きで特定。
  - 単なる文字列一致ではなく、参照関係・制御フロー・データフロー・命令統計の裏付けをもとに多角的に評価します。
- **セマンティック IR & 日本語要約**
  - アセンブリ言語の直訳にとどまらず、データフローや呼び出し関係を抽象化した Semantic IR を構築。
  - 関数の役割や処理の流れ（「データをコピー」「条件判定」「値を更新」など）をわかりやすい日本語で要約表示します。
- **豊富なメタデータ復元**
  - **Objective-C**: `__objc_classlist` やセレクタ参照から、クラス構造・メソッド名・プロパティ、および `[x0, #0x20]` などのインスタンス変数（フィールド）へのアクセスを自動解決。
  - **C++ / Swift**: Itanium ABI / Swift シンボルのデマングル、RTTI および vtable の抽出。
  - **Unity (IL2CPP)**: `global-metadata.dat` を読み込むことで、難読化・ストリップされたバイナリでも C# のクラス名やメソッド名を復元。
- **充実した解析ツール群**
  - **擬似コード生成 (Decompiler)**: 制御フローと式を解析し、C言語風の構文へ復元。
  - **制御フローグラフ (CFG) & コールグラフ**: SVG によるインタラクティブなブロック図描画。
  - **ブラウザ内 ARM64 エミュレータ**: ステップ実行、ブレークポイント、レジスタ・メモリ監視（実機不要）。
  - **バイナリパッチ & エクスポート**: 命令の改変（nop化、条件反転など）を行い、編集後バイナリを出力。
  - **JavaScript スクリプト & プラグイン**: 独自の解析処理を JavaScript で記述して自動化可能。
- **学習・初学者向けサポート**
  - 約200種類の ARM64 命令に日本語解説・計算式表示を完備。
  - ゼロからアセンブリを学べる 10 章の学習コースと約 60 語の用語集を内蔵。
  - ファイルを用意しなくてもすぐに試せる「サンプルバイナリ」をワンクリックで生成可能。

## 画面構成・解析の流れ

```
バイナリ入力 (Mach-O / Raw)
  │
  ├─ 1. セクション走査 & 索引作成（呼び出し関係・データ参照・命令統計）
  ├─ 2. メタデータ抽出（Objective-C / RTTI / シンボル / 文字列分類）
  ├─ 3. アプリ全体の構造化（機能マップ / コンポーネント分類）
  │
  └─ 対話型解析
       ├─ 擬似コード & アセンブリ表示（日本語解説付き）
       ├─ 制御フローグラフ (CFG) & コールグラフ
       ├─ フィールド追跡（どのメソッドがどの変数を変更しているか）
       └─ ARM64 エミュレーション & パッチ作成
```

## クイックスタート

### 動作要件
- モダンブラウザ（Safari, Chrome, Firefox, Edge）
- iPad / タブレットのタッチ操作・キーボード操作にも最適化されています。

### ローカルでの実行方法

本リポジトリは純粋な静的 Web アプリケーション（HTML / CSS / JavaScript / WebAssembly）です。Web Worker および Wasm のセキュリティ制約上、HTTP/HTTPS サーバー経由で配信して開く必要があります。

```sh
# リポジトリのクローン
git clone https://github.com/rhgrive3/hex-ida.git
cd hex-ida

# 簡易HTTPサーバーの起動（例）
npx serve .
# または
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開き、**「サンプルで練習する」** をクリックすると、練習用 ARM64 バイナリが即座に読み込まれます。

### GitHub Pages でのホスティング
リポジトリを GitHub に push し、リポジトリ設定から GitHub Pages（Source: Deploy from a branch, Branch: main / root）を有効化するだけで、ビルド不要で公開・利用可能です。

## 主な機能とツール

| 機能名 | 説明 |
| --- | --- |
| **自動解析 & アプリの地図** | バイナリ読み込み時に数万の関数をコンポーネント別に分類。注目すべき関数や通信先、改造検知文字列を抽出。 |
| **目的検索** | 「HP」「課金」「ガチャ」「通信」などの関心事から、担当関数・フィールドを高精度に特定。 |
| **逆アセンブラ** | 仮想スクロール対応の ARM64 ビューア。行ごとに日本語解説と数式表現を併記。 |
| **擬似コード (Decompiler)** | 制御構造（if / loop / switch）を復元した C 風コード表示。 |
| **グラフビュー (CFG / Callgraph)** | SVG による関数のブロック分岐図、および関数間の呼び出し依存図。 |
| **型・構造体復元** | 関数の引数・戻り値の型推測、オブジェクトオフセットからの構造体自動定義。 |
| **ARM64 エミュレータ** | ブラウザ完結のステップ実行・レジスタ変更・メモリ書き換え・逆トレース。 |
| **バイナリパッチ** | 命令の NOP 化や分岐反転、カスタム命令書き込みを行い、修正後バイナリを保存。 |
| **スクリプト & プラグイン** | `hex.functions()`, `hex.decompile()`, `hex.rename()` などの JavaScript API による拡張。 |

## 対応フォーマットと制限事項

- **対応アーキテクチャ**: ARM64 (AArch64) に特化しています。
- **ファイル形式**: Mach-O (iOS / macOS 実行ファイル・dylib)、生バイナリ。
- **暗号化バイナリ**: App Store 配布時の FairPlay 暗号化（`cryptid = 1`）が施された状態のバイナリは直接解析できません。復号済みのバイナリをご利用ください。
- **エミュレーションの範囲**: システムコールや iOS システムライブラリの内部動作はエミュレートされず、スタブとして戻り値 0 で安全に処理されます。
- **パッチ適用バイナリ**: パッチ保存後のバイナリを実機で実行する場合は、環境に応じたコード署名（codesign / ldid）が別途必要です。
