# L5: x86-64 Decoder (`cpp/src/targets/x86_64_decode`)

統合済み `wasm/hex_engine.wasm`（`scripts/build-wasm.mjs`）に組み込まれている freestanding C++20/WASM x86-64 デコーダの現行仕様。

## 対象ファイル

- `cpp/src/targets/x86_64_decode.hpp`
- `cpp/src/targets/x86_64_decode.cpp`
- `cpp/tests/test_x86_64_decode_native.cpp`

## 実装内容

- **Freestanding C++20/WASM & 公開 C ABI (`HEX_WASM_EXPORT`)**:
  - `hex_abi.hpp` / `hex_core/hex_core.hpp` のみを使用（STL・例外・RTTI 不使用）。
  - 公開 C ABI 6 関数: `hex_x86_64_decode_one`, `hex_x86_64_decode_batch`, `hex_x86_64_insn_length`, `hex_x86_64_kind_decomp_cap`, `hex_x86_64_is_decompiler_supported`, `hex_x86_64_kind_name`。
  - REX / `66` / ModRM / SIB / RIP 相対 / disp8・disp32 / 15 バイト上限および主要命令（`mov`/`movabs`, `movzx`, `movsx`/`movsxd`, `add`/`sub`/`xor`/`and`/`or`/`adc`/`sbb`/`cmp`/`test`/`inc`/`dec`/`neg`/`not`/`shl`/`shr`/`sar`, `imul`, `lea`, `jmp`/`jcc`, `call`, `ret`, `push`/`pop`, `nop`/`endbr64`）と `HEX_X86_CAP_DECOMP` / `HEX_X86_CAP_FALLBACK` 対応表を実装。
- **fail-closed 判定 (`hex_x86_64_is_decompiler_supported`)**:
  - バッファ全体を終端まで逐次デコードし、トランケート命令（`e8 01 00`, `e9 01 00`, `0f 8e 0e 00`, `f3 0f 1e`、ModRM/SIB/disp/imm 途中切れ等）・未対応プレフィックス（`f0`/`f2`/`f3`/`67`/セグメント/重複 `66`/連続 REX）・不正 ModRM（`lea` の `mod==3`, `c7 /reg!=0`）・15 バイト超・未知オペコード・空/NULL 入力で必ず `0` (`HEX_X86_CAP_FALLBACK`) を返す。

## 検証

- **Native テスト**: `cpp/tests/test_x86_64_decode_native.cpp`（ASan + UBSan、実バイナリ 3 種 `vertical-sysv-amd64.elf` 25 命令 / `vertical-microsoft-x64.exe` 26 命令 / `vertical-macho-x86_64.o` 25 命令の計 76 命令一致、およびトランケート・未対応プレフィックス・不正 ModRM・15B 超負テスト）。
- **WASM 統合ビルド**: `node scripts/build-wasm.mjs` により `wasm/hex_engine.wasm` に統合ビルドされる（上位層として `cpp/src/targets/x86_64_decomp.{hpp,cpp}` および `cpp/src/targets/x86_64_semantic_emit.{hpp,cpp}` も存在する）。
