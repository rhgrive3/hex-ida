## 2026-09-16 C4-04 proof-gated adoption の更新

C4-04 の既存 scalar proof gate は requested-target decision、frozen width/operator matrix、actual committed/rendered publication まで接続済みです。今回さらに、独立に到達不能と証明できた conditional region について、**no PHI / no MemoryPHI の flat-store body に限り**、private な exact-region/body authority を使って rendered C AST の不要 arm を実際に削除する境界を接続しました。canonical Semantic IR / SSA / CFG は変更しません。producer-bound tombstone と完全な provenance/history が欠ける場合、region/body が stale な場合、history budget が不足する場合は変換を公開せず rollback します。

これは FR-C4-04B 全体の完了ではありません。terminal return、全 terminal memory byte、terminal control target は versioned observable として比較できますが、native fault/exception/unwind、任意 memory/CFG rewrite、bounded-loop semantic equivalence、ordinary legacy-view 全体の adoption と exhaustive per-rule/full-width denominator は残ります。したがって HEX-C4-04 / FR-C4-04A / FR-C4-04B は引き続き **partial**、全体は **CHECKPOINT-LOCKED** / transformAuthorization:false です。

これを bundle membership のみの fail-closed 実装として追加した。projection 自身の

destination にせず operand として消費しない）が成立する間だけ `display-carrier` を返し、
失われた場合は `status:'unavailable'` かつ `isCurrent():false` を返す。
predicate・operand 同値・flag 事実は一切 discharge しない。

現 head での実測（この作業環境）:

| 対象 | 結果 |
|---|---|
| handoff の import 解決 | 通過（修正前は module load 自体が失敗） |
| `node --test tests/phase8/c4-local/normal-completion-scope.test.mjs` | 3 tests / 3 pass / 0 fail |

handoff が残した2件の first failure は解消した。両方とも「`complete` 実行が
unmodeled な fault/unwind annotation を肩代わりしてしまう」という同一の欠陥で、
admission 側（新規実行）と revocation 側（既発行 capability）の両方に穴があった。

- admission: `symbolic/memory/execution-contract.js` の `validateExecutionContract` は
  fault 則を実装しておらず、余剰引数として無視していた。canonical な
  `extra.attributes.machineEffects` bundle だけを唯一の fault/unwind 権威とし、
  instruction / `extra` / `attributes` 層に付いた fault・throw・unwind・cleanup・
  exception 宣言は `unsupported-instruction-exceptional-edge-annotation` で
  fail closed するようにした（`false` は既存の compatibility obligation 走査と
  同じく明示的な discharge として扱う）。
- revocation: `symbolic/memory/execution-snapshot.js` の capture 契約は
  instruction と `extra` の watch 語彙に fault/unwind obligation を含んでいなかった。
  `mayThrow` / `mayUnwind` / `unwindTarget` / `unwindMetadata` / `cleanupOrder` /
  `exceptionTargets` / `exceptionalEdges` を両層の SHAPES に加え、発行後に付加された
  annotation が既発行 result と snapshot を失効させるようにした。
  `attributes` 層は producer 側で non-extensible のため付加自体が起こらない。

なお handoff 同梱の `js/semantics/compat/effect-obligations.js`
