# Requirements Checklist

- [x] Artifact and collision-set schemas are explicit.
- [x] Working-view withdrawal and alternative retention are separate.
- [x] No forced choice or score-to-truth promotion exists.
- [x] Producer/binary/snapshot/source/architecture identity is retained.
- [x] Partial, stale, cancel, and budget publication rules are explicit.
- [x] Deterministic ordering and identity are testable.
- [x] ToolRegistry and rebuild consumer paths are named.
- [x] Typed symbolic identity and JSON reparse distinctions are explicit.
- [x] Start-only contained candidates remain collision-visible.
- [x] Canonical producer authority is live-issued, not caller-declared.
- [x] Production format-safe rebuild automatically binds and verifies discovery.
- [x] Backend discovery claims are scrubbed when canonical authority is absent.
- [x] Partial range observations and complete extent coverage are independent.
- [x] Interval IDs are factory-derived, unique, and fully ordered.
- [x] Reparse discovery is canonically derived from exact materialized bytes.
- [x] Fact-affecting format-safe work cannot bypass missing discovery.
- [x] Candidate, page-envelope, nested-record, and row accessors are never evaluated.
- [x] Nested parser partial status overrides enclosing complete status.
- [x] Publication verifies committed bytes and never exposes mutable validated bytes.
- [x] Validation/discovery/publication propagate cancellation and fixed ceilings.
- [x] Positive, negative, adversarial, boundary, malformed, stale, cancellation,
      budget, partial, regression, and determinism cases are covered.
- [x] Forbidden Phase 8, MemorySSA, solver, MachineEffects, threshold,
      denominator, workflow, ownership, and generated-output areas are excluded.
